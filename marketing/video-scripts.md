## X Thread（7 推）

**1/7**
你收藏的 AI 比价表，可能已经作废了。

kimi-k3 的输入价，一天之内：

1.72 → 1.16 → 1.09 → 1.14（¥/1M）

我们盯了一晚，一天四次调价。🧵

**2/7**
这不是抓取噪声。我们对最后一次变化做了连续 3 次间隔采样，
确认是厂商真实调价。同一天 OpenRouter 还下架了 qwen3.8-max。

比价内容最大的敌人不是算错，是过期。

**3/7**
所以"已核验"必须是一枚会自己消失的徽章：

- 每日自动抓取平台公开价格
- 逐字段一致才挂"已核验"
- 源站改价/下架 → 自动降级为待核验
- 每次变动留痕（时间 + 前后值）

**4/7**
全部变动公开可查：[链接]/data-status

比如昨晚 deepseek-v4-1-flash 的输出价直接 -94.8%，
因为平台改了计费结构——这种事靠人盯是不可能的。

**5/7**
开发者福利：价格数据开放了免费 API

GET /api/prices
- 默认只返回已核验价格
- 支持 ?model= ?provider= ?format=csv
- 60 次/分钟，响应带数据截至时间

文档：[链接]/data-api

**6/7**
非开发者也别走：Google Sheets 一条公式

=IMPORTDATA("https://tokenbibi.example.com/api/prices?format=csv")

价格表自动进表格，每天跟着更新。

**7/7**
工具叫 token比比：不要只看 token 单价，先看真实到手成本。

- 比价（默认仅已核验）：[链接]/models
- 降价动态：[链接]/price-drops
- 降价通知：RSS [链接]/feed.xml

数据全公开，欢迎指错。
