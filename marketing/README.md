# token比比 · 零预算发布工具包

本目录把营销方案转成可以直接执行的发布资产。

## 文件

- `launch-plan.md`：7 天冷启动和 30 天节奏
- `community-posts.md`：社区、X、知乎、GitHub 发布文案
- `outreach-templates.md`：平台方、创作者、开源项目合作模板
- `content-calendar.csv`：30 天内容日历
- `metrics.csv`：渠道与转化记录模板

## 使用原则

1. 先发结论，再发工具
2. 每篇内容都带一个可验证数字
3. 不刷屏，不夸大，不承诺收益
4. 广告、赞助、AFF 必须标注
5. 先做 7 天，再根据数据决定下个 30 天
