# token比比 — 关键决策备忘

## D1. 计费维度
- **采用**：
  1. 按量计费
  2. 订阅计费
  3. 积分 / 点数 / credits / 额度
  4. 卡密 / 兑换码 / 网卡
- **拆分原则**：
  - 按量、订阅、积分属于一级成本口径。
  - 卡密 / 网卡属于购买路径、支付方式和风险维度，不直接作为价格倍率。

## D2. 技术栈
- **采用**：Next.js + TypeScript + Tailwind CSS + 静态 JSON 数据
- **理由**：
  - 适合低成本部署和静态生成
  - 便于 SEO 和分享页
  - 数据可版本控制
  - 后续可迁移到数据库

## D3. 商业模式
- **初期**：不依赖广告位
- **后期**：固定数量广告位 + 明确标注 + 不影响排序
- **判断**：PriceAI 的广告位模式是可行的补充，但 0-1 阶段不应作为核心收入。

## D4. 营销优先级
- **结论**：营销是产品前提，不是后置动作。
- **必须先做**：
  1. 真实成本对比
  2. 成本计算器
  3. 分享卡片
  4. 分享链接
  5. GitHub README

## D5. 数据策略
- **初期**：人工核验 + 公开来源 + 定期快照
- **后续**：用户提交 + 管理后台 + 真实调用监测
- **原则**：每条价格必须有来源和更新时间。

## D6. MVP 边界
- **做**：比价、计算、路径选择、风险提示、分享。
- **不做**：交易、账号买卖、担保、灰色渠道、复杂 benchmark。
