## TC-1 数据模型校验

### TC-1a 模型数据格式
- **类型**：自动化
- **前置条件**：`models.json` 存在
- **步骤**：
  1. 读取模型数据
  2. 校验 `id`、`name`、`vendor`、`family`
  3. 校验能力标签为数组
- **预期**：所有模型通过 Zod 校验
- **优先级**：P0
- **关联 FR**：FR-1、FR-7

### TC-1b 平台数据格式
- **类型**：自动化
- **前置条件**：`providers.json` 存在
- **步骤**：
  1. 读取平台数据
  2. 校验 `type` 是否为合法枚举
  3. 校验官网地址为合法 URL
- **预期**：所有平台通过校验
- **优先级**：P0
- **关联 FR**：FR-2、FR-7

### TC-1c 价格来源必填
- **类型**：自动化
- **前置条件**：价格数据存在
- **步骤**：
  1. 读取每条价格
  2. 检查是否存在 `sourceUrl`
  3. 检查是否存在 `lastVerifiedAt`
- **预期**：每条价格都有来源和核验时间
- **优先级**：P0
- **关联 FR**：FR-7

## TC-2 计费路径

### TC-2a 按量计费
- **类型**：自动化
- **前置条件**：存在 `pay_as_you_go` 价格
- **步骤**：
  1. 构造一条按量价格
  2. 计算输入成本
  3. 计算输出成本
- **预期**：
  - 输入成本 = 输入价 × 输入 tokens
  - 输出成本 = 输出价 × 输出 tokens
- **优先级**：P0
- **关联 FR**：FR-1

### TC-2b 订阅计费
- **类型**：自动化
- **前置条件**：存在订阅套餐
- **步骤**：
  1. 构造月费 100 元、额度 50M tokens 的套餐
  2. 计算 10M tokens 成本
- **预期**：
  - 每 1M tokens 成本 = 100 / 50 = 2 元
  - 10M tokens 成本 = 20 元
- **优先级**：P0
- **关联 FR**：FR-3

### TC-2c 积分 / credits
- **类型**：自动化
- **前置条件**：存在充值汇率
- **步骤**：
  1. 构造 `1 元 = 1.2 额度`
  2. 计算充值系数
  3. 计算 1M tokens 成本
- **预期**：充值系数和有效成本正确
- **优先级**：P0
- **关联 FR**：FR-4

### TC-2d 卡密 / 兑换码
- **类型**：自动化
- **前置条件**：存在卡密规则
- **步骤**：
  1. 构造支持兑换码的平台
  2. 校验 `supported`、`riskLevel`
- **预期**：能正确展示支持状态和风险，不参与价格倍率计算
- **优先级**：P1
- **关联 FR**：FR-5

## TC-3 有效成本

### TC-3a 标价与充值汇率
- **类型**：自动化
- **前置条件**：标价 1 元 / 1M tokens，充值汇率 `1 元 = 0.8 额度`
- **步骤**：
  1. 计算充值系数
  2. 计算有效成本
- **预期**：有效成本高于标价
- **优先级**：P0
- **关联 FR**：FR-4

### TC-3b 模型倍率
- **类型**：自动化
- **前置条件**：模型倍率为 1.2
- **步骤**：
  1. 输入基础标价
  2. 应用模型倍率
  3. 应用充值系数
- **预期**：有效成本 = 标价 × 倍率 × 充值系数
- **优先级**：P0
- **关联 FR**：FR-4

### TC-3c 分组倍率
- **类型**：自动化
- **前置条件**：存在分组倍率 0.8
- **步骤**：
  1. 应用分组倍率
  2. 与基础价格比较
- **预期**：分组倍率正确影响成本
- **优先级**：P0
- **关联 FR**：FR-4

## TC-4 订阅比较

### TC-4a 订阅是否划算
- **类型**：自动化
- **前置条件**：存在按量和订阅两条数据
- **步骤**：
  1. 输入月输入 10M tokens、输出 5M tokens
  2. 计算按量成本
  3. 计算订阅成本
  4. 输出推荐路径
- **预期**：返回成本更低者
- **优先级**：P0
- **关联 FR**：FR-3、FR-6

- **步骤**：

- **预期**：破局点为 10M tokens
- **优先级**：P0
- **关联 FR**：FR-3、FR-6

### TC-4c 超额规则
